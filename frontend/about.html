Based on Lichess

This website is based in part on source code and assets from Lichess, including its open-source chessboard library, Chessground. Lirep.org also uses Stockfish for chess analysis. It is an independent project and is not an official Lichess service.

Like the code of Lichess, the code of Lirep is released under the GNU AGPL-3.0-or-later.

Similar tools

Lirep is one of several free and open-source tools for building and drilling an opening repertoire. Its unique features include:

  • Easy sign-in with your Lichess account.
  • New metrics to evaluate an opening, such as the expected score (win % plus half the draw %) of your whole repertoire, calculated assuming the opponent plays moves according to probabilities given by the Lichess opening explorer, as well as the expected evaluation when reaching the end of preparation.
  • Easy sharing of studies with the community, and a one-click import of someone else's opening.
